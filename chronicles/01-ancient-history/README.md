# Volume I - Ancient History

Period: before 2700 BB.

Main account and historical narratives for this period.

- [Volume I — working draft](./volume-I.md): prose fragments and placeholders for the eventual volume.
- [Draft notes](./draft-notes.md): sources, chronology questions, and limits on the compiler's knowledge.

The original publication is Volume I. Later collections are Volume I.II, Volume I.III, and so on, kept in this folder as separate manuscripts. See the [publication structure](../README.md#additional-volumes-within-each-period).
